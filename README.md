# رحلة الصين الكبرى (20 يوماً) — موقع تفاعلي متكامل

إعادة تصميم شاملة ومعمارية معيارية (Industry-Standard Modular Architecture) لخطة رحلة الصين الكبرى لمدة **20 يوماً / 19 ليلة** (الرياض ⇄ بكين ⇄ شنغهاي ⇄ تشانغجياجيه ⇄ تشونغتشينغ ⇄ دالي ⇄ قوانغتشو ⇄ الرياض).

## أبرز المميزات المنفذة
- **تصميم مريح للعين (Easy on the Eye):** نظام ألوان هادئ ودافئ (Porcelain & Oriental Jade) مع إمكانية التبديل بضغطة زر إلى **الوضع الليلي المريح للعين**.
- **صفحة ملخص رئيسية شاملة (Summary Landing Page):** تعرض مسار الرحلة، الميزانية الكلية، ملخص المدن الست، دليل الفنادق المقترحة (5 نجوم)، والجدول الشامل للتكاليف.
- **الجدول اليومي المفصل (20 يوماً):** يوضح لكل يوم أين تذهب (الأنشطة والمعالم بالساعة)، كيف تصل إليها، الفنادق المقترحة، وماذا تأكل وتشرب.
- **العملة بالريال السعودي فقط (SAR Only):** تم توحيد جميع الأسعار والتكاليف بالريال السعودي (`ر.س`) فقط وإزالة أي عملات أجنبية.
- **تفصيل يومي لتكلفة كل نشاط (Daily Cost Breakdown Per Activity):** جدول تفصيلي داخل كل يوم يوضح تكلفة كل نشاط مقترح على حدة، بالإضافة لتكلفة التنقل، الفندق، والوجبات الحلال، وإجمالي اليوم بالريال السعودي.
- **معرض صور متعدد لكل يوم ولكل نشاط + متوافق مع الجوال (Mobile-Friendly):** يعرض 4 صور عالية الدقة لكل يوم تغطي جميع أنشطة اليوم مع عارض صور كامل (Lightbox).
- **روابط خرائط جوجل (Google Maps Links) لكل شيء:** كل مدينة، وكل فندق مقترح، وكل نشاط سياحي، وكل مطعم حلال مزود برابط مباشر لخرائط جوجل لعرض الموقع ومشاهدة المزيد من الصور.
- **طعام ومشروبات حلال 100%:** تم تدقيق وتنقيح جميع الوجبات والمطاعم والمشروبات على مدار الـ 20 يوماً لتكون حلالاً 100% وخالية تماماً من الكحول أو أي مكونات غير حلال.

## هيكل المشروع (Project Architecture)
```text
├── index.html                  # نقطة الدخول الرئيسية (HTML5 الدلالي مع دعم RTL)
├── package.json                # إعدادات المشروع وأوامر التشغيل
├── server.js                   # خادم محلي (Node.js) للتطوير والمعاينة
├── css/
│   ├── variables.css           # متغيرات التصميم والألوان (الوضع النهاري الدافئ والليلي المريح)
│   ├── base.css                # الخطوط العربية، الأساسيات، والأزرار والشارات
│   ├── layout.css              # الهيدر، شريط التصفية، الشبكات المتجاوبة، والفوتر
│   └── components.css          # بطاقات الملخص، بطاقات الأيام، معارض الصور، جداول التكاليف، والـ Lightbox
└── js/
    ├── utils/
    │   └── helpers.js          # دوال بناء روابط خرائط جوجل وتنسيق الريال السعودي
    ├── data/
    │   ├── citiesData.js       # بيانات ملخص المدن الست والفنادق (5 نجوم)
    │   └── itineraryData.js    # بيانات الـ 20 يوماً الكاملة والأنشطة والتكاليف والمطاعم الحلال
    ├── components/
    │   ├── SummaryPage.js      # مكوّن صفحة الملخص الرئيسية وجدول الميزانية الشامل
    │   ├── DayView.js          # مكوّن بطاقات الأيام المفصلة وتفصيل تكاليف الأنشطة
    │   └── LightboxModal.js    # مكوّن عارض الصور التفاعلي الكامل
    └── app.js                  # وحدة التحكم الرئيسية والتنقل والتصفية
```

## طريقة التشغيل
1. **التشغيل عبر خادم Node.js المحلي:**
   ```bash
   node server.js
   ```
   ثم افتح المتصفح على الرابط `http://localhost:3000`.
2. **أو الفتح المباشر:** يمكنك أيضاً فتح ملف `index.html` مباشرة في أي متصفح حديث.
