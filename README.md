# رحلة الصين الكبرى الفاخرة لشخصين (20 يوماً / 19 ليلة)

إعادة تصميم شاملة ومعمارية معيارية (Industry-Standard Modular Architecture) لخطة رحلة الصين الكبرى لمدة **20 يوماً / 19 ليلة**، محسوبة ومفصلة بالكامل **لشخصين (2 مسافرين)** بالريال السعودي (`ر.س`) فقط.

**مسار الرحلة:**  
`الرياض ⇄ بكين ⇄ شنغهاي ⇄ تشانغجياجيه ⇄ تشونغتشينغ ⇄ منتجع دالي ⇄ قوانغتشو ⇄ الرياض`

## أبرز المميزات المنفذة
- **تصميم مريح للعين ومتجاوب بالكامل مع الجوال (Mobile-First RTL):** نظام ألوان هادئ ودافئ (Porcelain & Oriental Jade) مع دعم التبديل إلى **الوضع الليلي المريح للعين**.
- **صفحة ملخص رئيسية شاملة (Summary Landing Page):** تعرض مسار الرحلة، الميزانية الكلية لشخصين، ملخص المدن الست، دليل الفنادق المقترحة (5 نجوم)، والجدول الشامل للتكاليف.
- **الجدول اليومي المفصل (20 يوماً):** يوضح لكل يوم أين تذهب (الأنشطة والمعالم بالساعة)، كيف تصل إليها، الفنادق المقترحة، وماذا تأكل وتشرب.
- **العملة بالريال السعودي فقط (SAR Only):** تم توحيد جميع الأسعار والتكاليف بالريال السعودي (`ر.س`) فقط لشخصين.
- **تفصيل يومي لتكلفة كل نشاط (Daily Cost Breakdown Per Activity):** جدول تفصيلي داخل كل يوم يوضح تكلفة كل نشاط مقترح لشخصين على حدة، بالإضافة لتكلفة التنقل، الفندق، والوجبات الحلال، وإجمالي اليوم بالريال السعودي.
- **معرض صور متعدد لكل يوم ولكل نشاط:** يعرض 4 صور عالية الدقة لكل يوم تغطي جميع أنشطة اليوم مع عارض صور كامل (Lightbox).
- **روابط خرائط جوجل (Google Maps Links) لكل شيء:** كل مدينة، وكل فندق مقترح، وكل نشاط سياحي، وكل مطعم حلال مزود برابط مباشر لخرائط جوجل (`230 رابط مباشر`).
- **طعام ومشروبات حلال 100%:** تم تدقيق جميع الوجبات والمطاعم والمشروبات على مدار الـ 20 يوماً لتكون حلالاً 100% وخالية تماماً من الكحول أو أي مكونات غير حلال.

## هيكل المشروع (Project Architecture)
```text
├── index.html                  # نقطة الدخول الرئيسية (HTML5 الدلالي مع دعم RTL)
├── package.json                # إعدادات المشروع وأوامر التشغيل
├── server.js                   # خادم محلي (Node.js) للتطوير والمعاينة
├── README.md                   # التوثيق الشامل وملخص الميزانية لشخصين
├── css/
│   ├── variables.css           # متغيرات التصميم والألوان (الوضع النهاري الدافئ والليلي المريح)
│   ├── base.css                # الخطوط العربية، الأساسيات، والأزرار والشارات
│   ├── layout.css              # الهيدر، شريط التصفية، الشبكات المتجاوبة، والفوتر
│   └── components.css          # بطاقات الملخص، بطاقات الأيام، معارض الصور، جداول التكاليف، والـ Lightbox
└── js/
    ├── utils/
    │   └── helpers.js          # دوال بناء روابط خرائط جوجل وتنسيق الريال السعودي
    ├── data/
    │   ├── citiesData.js       # بيانات ملخص المدن الست والفنادق (5 نجوم) لشخصين
    │   └── itineraryData.js    # بيانات الـ 20 يوماً الكاملة والأنشطة والتكاليف والمطاعم الحلال لشخصين
    ├── components/
    │   ├── SummaryPage.js      # مكوّن صفحة الملخص الرئيسية وجدول الميزانية الشامل لشخصين
    │   ├── DayView.js          # مكوّن بطاقات الأيام المفصلة وتفصيل تكاليف الأنشطة لشخصين
    │   └── LightboxModal.js    # مكوّن عارض الصور التفاعلي الكامل
    └── app.js                  # وحدة التحكم الرئيسية والتنقل والتصفية
```
